# fragments

Fragments API for Seneca's CCP555: Cloud Computing

## Scripts

To run the various scripts for this API, you need to execute the following commands:

- To start the API: `npm start`
- To start the API in developer mode: `npm run dev`
- To start the API in debug mode: `npm run debug`
- To lint the project: `npm run lint`

---

If the project isn't working, run `npm init` before you start debugging anything :)
